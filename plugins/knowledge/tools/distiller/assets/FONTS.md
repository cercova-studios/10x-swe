# Bundled cover font

NotoSans-Bold.ttf is the unmodified static font from
https://github.com/notofonts/noto-fonts/blob/main/hinted/ttf/NotoSans/NotoSans-Bold.ttf
(downloaded 2026-10-13). NotoSans-LICENSE.txt is its upstream SIL Open Font
License 1.1. The binary embeds both font bytes and license text; composed cover
images are not font distributions. The cache specification includes the font's
SHA-256 identity. Current local typesetting supports precomposed Latin, Greek,
Cyrillic and supported punctuation, and rejects complex shaping and combining
marks. Supply a finished cover for unsupported scripts.
