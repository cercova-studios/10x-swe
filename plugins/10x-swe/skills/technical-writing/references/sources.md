# Sources and adaptation

This is locally authored technical-writing guidance combining developer-documentation
practice, meaning-preserving editing and source-grounded review. It condenses and
adapts the following sources rather than installing their instructions or scripts.

- [danyuchn/asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill), revision `3944283c183eea13fe5bd902b572da3b4de8bf44`: [skill](https://github.com/danyuchn/asd-ste100-skill/blob/3944283c183eea13fe5bd902b572da3b4de8bf44/SKILL.md) and [writing rules](https://github.com/danyuchn/asd-ste100-skill/blob/3944283c183eea13fe5bd902b572da3b4de8bf44/references/writing-rules.md). MIT; its copyright/license notice is retained in [upstream license](upstream-asd-ste100-LICENSE.txt). Adaptations use flexible sentence targets, preserve project voice, and add repository facts, README structure and multi-agent review. No upstream executable is included.
- Google, [developer documentation style guide](https://developers.google.com/style), particularly [highlights](https://developers.google.com/style/highlights), [voice and tone](https://developers.google.com/style/tone), [procedures](https://developers.google.com/style/procedures) and [code samples](https://developers.google.com/style/code-samples). Guidance is condensed and paraphrased here with project-first precedence. Text is offered by Google under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/); Google's code examples have their own Apache 2.0 terms. No Google code samples are copied.
- GitHub, [about READMEs](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-readmes), and GDS, [writing READMEs](https://gds-way.digital.cabinet-office.gov.uk/manuals/readme-guidance.html): purpose, usefulness, first use and concise navigation to deeper documentation.

STE-inspired guidance here is not the official ASD-STE100 standard or dictionary.
The official standard remains available through [ASD](https://www.asd-ste100.org/).
Preserve the attribution and source license notices when redistributing this bundle.
