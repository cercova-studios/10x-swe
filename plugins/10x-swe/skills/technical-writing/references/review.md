# Review writing with complementary agents

For a substantive rewrite, separate responsibilities when delegation is authorized:

1. Investigator: inspect current source/help and supply a compact capability brief, audience, prerequisites, effects and exact examples. Give the writer affirmative facts; reserve adversarial bad claims and failure cases for the reviewer to avoid priming the public copy with them.
2. Writer: draft from that brief. For an independent alternative, withhold the original prose to reduce imitation.
3. Technical reviewer: challenge claims, implied guarantees and command behavior against source. A different model can offer another perspective; it is not independent evidence by itself.
4. Editor: combine the clearest explanations with accurate coverage; remove duplication and preserve product voice.
5. Fresh reader: explain usefulness and attempt the first task, recording friction outside user-facing docs.

One agent may perform sequential passes for smaller changes. Choose models for
available tools, context, permissions and observed task results. A Claude draft
can be useful for conceptual explanation while a repository-oriented agent checks
contracts and runs examples; those assignments are hypotheses to evaluate, not
permanent model rankings. Do not add extra agents to meet a ceremonial checklist.

Compare candidates using reader comprehension, factual accuracy, successful first
use, coverage, organization and concision. Compare before revealing authorship
when practical. Keep the source brief identical and preserve raw drafts. Prefer
specific findings over unexplained numeric scores. Passing style checks does not
compensate for a false capability claim.

Useful fidelity probes: uncertainty must survive simplification; approval stays a
prerequisite; defaults and component-specific claims keep their scope; existing
flags and paths retain exact spelling. A shorter version that changes any of
these fails review. Keep test records and model metadata in the development
archive, not in the README or skill's normal output.
