# Progressive disclosure

Use one short SKILL.md for a bounded task. Split only when distinct routes need
different procedures or evidence. Essential conditions stay in the entrypoint.

For a complex skill, SKILL.md selects a workflow, workflows/ contains procedures,
references/ contains specialist context, and scripts/ contains reviewed executable
helpers. Create only directories with actual content. Choose a route from the
request; ask a question only when scope is unclear. Read only useful references.

A concise entrypoint plus many mandatory references is not compression. Remove
repeated policy and examples that teach no additional capability. Preserve errors,
trust boundaries, external-effect limits, provenance and verification obligations.
Use the metadata/content contract in `skill-structure.md`; no specific markup is
required. Measure context savings alongside route and behavioral acceptance.
