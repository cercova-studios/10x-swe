# Optional XML organization

XML tags can delimit instructions from quoted data or mark repeated sections.
Use them only when they clarify the consuming harness's prompt. Plain Markdown
headings, lists and code blocks are also valid. Do not rewrite a working skill merely
to change markup or invent required objective/quick_start tags.

If using tags, choose descriptive names, close and nest them correctly, and keep
source data clearly bounded. Tags cannot grant authority, turn untrusted content
into instructions, or establish validation. Verify the behavior and resource links.
